# Free-Panel · 更加自由的导航页（PHP + SQLite）

一款面向局域网（内网）的导航/收藏夹面板，布局与功能参考 [Sun-Panel](https://github.com/hslr-s/sun-panel)：**登录认证 → 分组收藏夹 → 多模式地址访问**，纯 PHP + SQLite 实现，零外部依赖，单文件启动。

> 项目主页：[https://github.com/yaobus/Free-Panel](https://github.com/yaobus/Free-Panel)

![MainPage](https://github.com/yaobus/ProjectData/blob/0a978e73734e1fcca80aa1b36a609178b48d1d9b/FreePanel/%E4%B8%BB%E9%A1%B5.png)


## 功能特性

- **登录认证**：bcrypt 密码哈希、连续失败 5 次锁定 5 分钟、CSRF 防护
- **底部备案（可选）**：默认不预置备案文本；在「设置 → 备案信息」填写后，**仅登录页**底部显示（最多 2 条：ICP + 公安备案），**点击备案文字可跳转到对应官网**（新窗口打开），登录成功后的主页底部不显示任何内容；备案跳转链接保留默认值（工信部官网 / 公安备案查询，含 `{q}` 占位符自动替换备案号），仅在手动修改后使用新地址，链接留空则不跳转（纯文本显示）
- **分组收藏夹**：分组导航侧栏（可开关）+ 图标卡片网格 + 顶部搜索（`/` 快捷键）
- **图标内嵌保存（加载提速）**：新增 / 编辑地址卡片、搜索引擎、分组与站点图标时，从「图标库」选中 Iconify 图标即抓取 SVG 内容并转为 `data:image/svg+xml;utf8,…` **直接保存到数据库**——页面渲染零外部请求，内网 / 离线也能立即显示，加载更快；外网不可用时自动回退保存 `iconify:名称`（保持原有行为）
- **三模式地址**：每个收藏可配置 **默认 / 内网 / IPv6** 三个地址；顶部「默认 / 内网 / IPv6」切换按钮决定点击卡片打开哪个地址；未配置的地址自动回退到默认地址并提示
- **拖拽排序（无需管理模式）**：卡片**随时**可按住拖动——组内排序、拖到其他分组完成移动；拖动**分组名称**可调整分组顺序
- **右键菜单**：在任何收藏卡片上右键，弹出 编辑 / 删除
- **悬浮添加按钮**：鼠标移到分组名称上，名称右侧浮现「＋」按钮，点击即在该分组添加收藏；鼠标移开 2 秒未点击自动隐藏
- **侧栏添加分组**：左侧「分组导航」标题前带文件夹图标，字号与右侧分组名称一致；鼠标悬停标题时末尾浮现「＋」按钮，点击即可新建分组（移开 2 秒自动隐藏）；添加 / 编辑收藏时「所属分组」下拉框旁也提供内联「＋」，新建分组后自动选中且不打断当前填写
- **站点设置**（顶部 ⚙ 按钮，随时可开）：
  - 站点名称 / 副标题 / **站点图标**（emoji、图片 URL 或 iconify:图标名，可点击「图标库」从 Iconify 在线图标库选取）/ **网站 LOGO**（登录页图标与主页左上角图标，支持本地上传 JPG / PNG / SVG，或填写图片 URL / iconify:名称 / emoji）/ 备案信息（可选，默认留空）
  - 链接新窗口开关、**左侧分组导航显示/隐藏**
  - **网页背景**：默认渐变 / 自定义纯色（取色器）/ 自定义图片（URL）
  - **页面边距**（0–80px）
  - **搜索栏设置**：显示/隐藏搜索栏、本地搜索（输入实时过滤）、互联网搜索（回车调用搜索引擎）、搜索提示文本；搜索引擎列表（名称/地址/图标，搜索框旁可增删改）持久化保存到数据库
  - **账号设置**：修改用户名（需验证当前密码，修改后下次登录用新用户名）、修改密码（已并入设置页）
  - **关于**：展示站点名称 / 副标题 / 版本 / 技术栈 / 简介 / GitHub 项目链接（图标）/ 版权等只读信息
- **明暗主题**：一键切换并记忆
- **响应式布局 + 顶栏折叠**：适配桌面 / 平板 / 手机；当屏幕宽度 ≤ 720px 时，顶部右侧的「切换主题 / 站点设置 / 退出登录」自动折叠为「⋮ 更多」按钮，堆叠为下拉面板（点击面板外或按 Esc 关闭），保持界面清爽
- **图标**：emoji / 图片 URL / 自动 favicon 三选一，加载失败自动降级为首字彩色头像

## 环境要求

- PHP 7.4+（推荐 8.x），需启用 `pdo_sqlite` / `sqlite3`（官方 Windows 发行版默认包含）
- 无需 MySQL、无需 Composer、无需外网

## 快速开始

### Windows（双击运行）

双击 `start.bat`，浏览器访问 `http://localhost:8080`

### 命令行

```bash
cd sun-nav
php -S 0.0.0.0:8080 -t .
```

- 本机访问：`http://localhost:8080`
- **局域网访问**：`http://<本机IP>:8080`（例如 `http://192.168.1.100:8080`）
  - Windows 首次启动若弹出防火墙提示，勾选「专用网络」并允许；或在防火墙高级设置中放行 8080 端口
- 换端口：把命令中的 `8080` 换成其他端口即可

## 使用说明

1. **登录**：输入用户名密码，错误 5 次后锁定 5 分钟
2. **浏览**：点击卡片打开地址（默认新窗口）；顶部切换 默认/内网/IPv6 决定打开的地址类型；搜索框实时过滤收藏夹，回车调用当前搜索引擎联网搜索
3. **管理（无独立管理模式，随时可用）**：
   - 直接**按住卡片拖动**：调整组内顺序，或拖到其他分组
   - 拖动**分组名称**调整分组顺序
   - 鼠标移到分组名称上浮现「＋」，点击在该分组添加收藏
   - **右键卡片**弹出 编辑 / 删除
   - 鼠标悬停卡片右上角 ✎/🗑 或分组名右侧 ✎/🗑 也可编辑删除
   - 点击顶部 ⚙ 打开站点设置（标题、备案、侧栏、背景、边距、账号、改密、搜索栏、LOGO、关于）
4. **添加收藏**：名称 + 默认地址必填，内网/IPv6 地址可选（留空则该模式自动回退默认地址）；图标支持 emoji（如 `🔧`）或图片 URL；卡片背景默认选中色板第一个颜色卡片，可改默认背景 / 透明 / 自定义颜色

## 目录结构

```
sun-nav/
├── config.php      # 默认配置（标题 / 备案 / 账号 / 背景 / 边距）
├── db.php          # SQLite 连接、建表、迁移、种子数据、设置读写
├── auth.php        # 会话 / 登录校验 / CSRF
├── login.php       # 登录认证页（底部 2 条备案）
├── index.php       # 收藏夹主页
├── api.php         # JSON 管理接口（分组/链接/排序/设置/改密）
├── logout.php      # 退出登录
├── assets/
│   ├── style.css   # 样式（明暗双主题）
│   └── app.js      # 前端交互（搜索/拖拽/右键/弹窗/模式切换）
├── data/           # SQLite 数据库（自动生成）
└── start.bat       # Windows 一键启动
```

## 常见问题

- **数据库已存在但缺少新字段**：无需手动处理，`db.php` 会自动 `ALTER TABLE` 迁移
- **端口被占用**：换一个端口启动即可
- **页面 404/空白**：确认使用的是 `php -S` 或配置了 PHP 的 Web 服务器，且目录指向 `sun-nav`
- **想重置数据**：停止服务后删除 `data/nav.db`，重启会自动重建并写入默认管理员与示例数据
